# Minha Dieta

Página privada (não listada) com o plano alimentar de Thulio, organizada por refeição.

## Conteúdo

- `index.html` — página do plano alimentar, com abas por refeição (café, almoço, lanche/ceia, jantar) e substituições em acordeão
- `robots.txt` — bloqueia indexação por mecanismos de busca

## Publicar no GitHub Pages

1. Em **Settings → Pages → Source**, selecione a branch `main` e a pasta `/ (root)`
2. A página fica disponível em `https://thuliolf.github.io/minhadieta`

## Usar um domínio próprio (opcional)

Para publicar em um subdomínio como `dieta.thulio.com.br`:

1. Crie um registro DNS `CNAME` apontando `dieta` para `thuliolf.github.io`
2. Adicione um arquivo `CNAME` na raiz do repositório contendo `dieta.thulio.com.br`

## Privacidade

Esta página não é protegida por senha — ela está apenas sem link público e fora dos buscadores (`robots.txt`). Qualquer pessoa com a URL exata consegue acessá-la.
